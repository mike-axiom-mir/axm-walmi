# WALDO v0.46 — portable continuation capsule

Status: **EXPERIMENTAL / TEST**

v0.46 gives the standalone WALDO body a deterministic continuation mechanism that can travel between machines or model hosts without depending on the AXM Workshop. It compiles a small explicit declaration plus exact linked source digests into a path-independent continuation capsule and compact resume card, and can later reverify the linked files.

The runtime/support graft contains the continuation core, host, schemas, CLI, Windows Node launcher, module declarations and the exact checkpoint digest helper it requires. The Keel-specific example declaration and historical AXM evidence receipts are deliberately excluded.

Two Memory & Continuity Garden compiled contracts are retained only as inert reference fixtures because the donor selftest verifies that the re-entry and session-handoff identities it references actually exist. They are not activated, installed as WALDO memory authority, or granted any permission.

The capsule embeds neither linked source content nor source input paths. Private/user material, raw/repetitive telemetry, temporary captures and unclassified sources are refused. Volatile facts remain `REPROBE_REQUIRED`; a stored digest is not external freshness proof.

Continuation is context/provenance transport, not hidden memory authority. It grants no automatic action, permission change, network, merge, promotion, roots or CANON authority.
