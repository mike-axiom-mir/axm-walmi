# WALDO v0.44 — cognitive evidence and calibration body

Status: **EXPERIMENTAL / TEST**

v0.44 vendors the public-safe shared cognitive-resource/evidence core into WALDO itself. It deliberately does not import the Cognitive Resource Meter product shell or its Technical Glasses service dependency.

The body can normalize privacy-safe model/tool/environment/resource observations, bind exact digests, keep token and compute dimensions separate, retain evidence with explicit classes, and compare declared prediction intervals against observed values through the cognitive evidence-lab core. Two small shared infrastructure helpers are vendored because the cognitive services genuinely depend on them: operations-utils and evidence-retention-service.

This is a measurement/calibration layer around a replaceable model, not a neural-weight change. The source core refuses hidden-reasoning/prompt/response capture, universal token-to-compute relabeling, model ranking/selection, optimization authority, training authority, CANON authority, and world action. Measurement may inform later evidence review but grants no action or promotion authority.
