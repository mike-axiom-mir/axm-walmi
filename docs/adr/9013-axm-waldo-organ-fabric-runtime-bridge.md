# 9013: Witness the deterministic Organ Fabric as a separate observed evidence plane

## Status

Accepted for `EXPERIMENTAL` v0.11 only.

## Context

v0.10 proved that one frozen concept could become multiple inert Code Fabric bodies while preserving one ancestor identity. The next AXM donor packet added a deterministic Organ Fabric and an Organ Archive, but both were still separate/unmerged source sets at capture time.

The packet was initially inspected statically. A later explicit human authorization permitted public publication and a disposable runtime experiment. Historical request and receipt bytes remain unchanged.

## Decision

Keep the Code Fabric receipt witness from v0.10 intact and add a **separate Organ-runtime witness** for v0.11.

The Organ-runtime receipt must bind:

- the exact donor packet SHA-256;
- the unchanged v0.10 concept SHA-256;
- runtime/factory identity and the exact `lean`, `balanced`, `guarded` strategy set;
- four proposal bodies, exactly one of which has `AI` source kind;
- three verified candidate packages per body;
- zero generation failures;
- advisory-only comparison with no selection;
- disposable Organ Archive verification, dedup behavior, and export/import identity;
- an explicit truth boundary preventing install/register/stage/promote/CANON claims.

The WALDO/Mirror side independently recomputes the external canonical JSON receipt digest and turns the verified receipt into a smaller closed-authority witness. It does not execute Organ Fabric code.

## Observed v0.11 result

The later-authorized disposable run executed the donor's focused Organ Fabric tests: 151 checks passed.

The unchanged challenge then produced 12/12 candidate slots:

- 4 proposals;
- 3 strategies each;
- 12 verified packages;
- 0 generation failures;
- 0 selections.

All 12 packages entered a fresh disposable archive. A duplicate reinsert was deduplicated without adding an event. Archive export/import into a second fresh store verified the same 12-object index.

Independent WALDO witness:

`2235bcfbdc1beefd4b3ec3835e1ad96eaf50433f58a393e3c1d102ad0c644db9`

## Consequences

- v0.10 remains the pre-Organ-Fabric measured baseline.
- v0.11 makes the Organ Fabric's contribution measurable without folding it into Code Fabric history.
- `AI` remains an untrusted proposal-source class; no live model call is required for deterministic generation/verification.
- strategy scores are evidence for comparison only and cannot silently select a candidate.
- Organ Archive is an append-only evidence store after candidate verification, not a proposal generator.
- publication does not merge the local donor branches into AXM platform `main` or OpenWALDO upstream.
