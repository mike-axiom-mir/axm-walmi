# ADR 9033: Specialist output is not grounding authority

## Status

Experimental research contract only.

## Context

AXM Collaboration Platform PRs #50 through #55 now expose a tested cumulative
Code Capability Fabric surface: language organs, specialist eyes, machine
heuristics, templates, and human discipline direction layers.

Those donor layers intentionally preserve candidate/evidence vs authority.
WALDO v0.31 already showed that a Grounding Membrane can reduce coupled
overreaction when coupling remains default and fallback remains bounded.

The next risk is accidental semantic promotion during integration: a useful
specialist output, a popular template, or many discipline directions could be
misread as truth or permission.

## Decision

1. Bind an exact donor checkpoint and exact interface blob identities.
2. Accept typed donor outputs; do not copy a second Platform execution path.
3. Specialist discovery is context/candidate, never grounding authority.
4. Discipline direction is perspective, never correctness proof.
5. Template verification is narrow mechanic verification, never instantiated
   source correctness.
6. Current provenance-bound verifier observations may pass a change into
   coupled reasoning.
7. Stale or unbound verifier observations remain uncertainty.
8. Grounding packets cannot synthesize execution permits.
9. Authority widening fails closed.
10. The existing ExecutionGuard remains the only simulated execution edge.

## Evidence

14/14 local contract tests PASS.

## Boundary

This does not prove the full Platform donor is safe, correct, or universally
useful. It proves the adapter's bounded translation semantics for the exact
schemas tested here.

No merge, install, promotion, publication, or CANON authority.
